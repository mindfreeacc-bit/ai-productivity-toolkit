# AI Productivity Toolkit

A practical open-source toolkit for using AI assistants productively, safely, and professionally.

## What this project includes

- Prompt templates for coding, writing, research, and planning
- Checklists for reviewing AI-generated work
- Safety notes for avoiding hallucinations, data leaks, and low-quality outputs
- Simple workflows for students, creators, and developers

## Project goals

This project helps people use AI tools as assistants, not shortcuts. The focus is on clarity, verification, responsible use, and repeatable workflows.

## Structure

- `templates/` — reusable AI prompt templates
- `checklists/` — review checklists before using AI output
- `examples/` — sample workflows

## Contributing

Contributions are welcome. You can add templates, improve wording, suggest safer workflows, or create examples.
